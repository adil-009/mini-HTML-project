# 👨‍💻 Adil Alam | Personal Profile Website

Welcome to my Personal Profile Website repository! This project is a simple HTML-based webpage created to introduce myself, showcase my interests and skills, and present my academic background.

As a first-year B.Tech Computer Science and Engineering student at Bennett University, I created this project to practise the fundamentals of HTML and learn how to structure a personal webpage.

## 📌 About the Project

This website serves as my basic digital profile. It introduces me, highlights my technical interests, and provides access to my LinkedIn profile.

### ✨ Features

- **Personal Introduction:** A brief introduction about me and my academic background.
- **Profile Picture:** Displays my personal photograph.
- **Skills and Interests:** Highlights my interests in Python programming, web development, and vibe coding.
- **LinkedIn Profile:** Provides a link to my LinkedIn account.
- **Academic Details:** Displays my educational background in a structured HTML table.

## 🛠️ Technologies Used

- **HTML5** — Used to structure the webpage and display its content.

## 🚀 How to Run the Project

You can view this project on your local computer by following these steps:

1. Clone this repository:

   ```bash
   git clone YOUR_REPOSITORY_URL
   ```

2. Open the downloaded project folder.
3. Make sure `index.html` and `ProfileImage.jpg` are in the same folder.
4. Open `index.html` in any modern web browser.

No additional installations or dependencies are required.
